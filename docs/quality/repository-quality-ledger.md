## Lint configuration

Direct `typeof` checks and `unknown` inputs are valid at trust boundaries. An
object check establishes `Record<string, unknown>`, not a domain-specific
contract. Do not create helper functions or type predicates to evade a rule.

The configured rules exclude bans on these patterns, compulsory assertion
comments, conditional object spreads, and domain-appropriate names such as
`assertIntentShape`. Effect rules were removed because they flagged ordinary
Flue factory functions as Effect services. Control-character regular expressions
remain permitted for input sanitization. Production double assertions remain
checked; deliberately partial test doubles are exempt from that rule.

## Verification

The new guidance catalog is covered by `tests/packaging-guidance.test.ts`: every required family is present, selected guidance renders in canonical order, the pinned upstream commit is visible, and empty/unknown selections fail. Existing recipe tests remain the guard for deterministic rendering and trust-boundary checks. No release, signer, worker, or publication code was changed for this ledger.

Remaining findings are tracked above with owners and a concrete verification condition. No raw line-count reduction or broad rewrite is treated as quality evidence.
